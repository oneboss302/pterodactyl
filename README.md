# pterodactyl.castafero.com

**Pterodactyl Tracker.** Last confirmed sighting: about 66 million years ago.

Every pterosaur fossil occurrence in [The Paleobiology Database](https://paleobiodb.org/) (CC BY 4.0) on one map:

- **Where they were found:** present-day locations, colored by period.
- **Where they lived:** PBDB's plate-tectonic reconstruction of each site at the time.
- A time slider (228 to 66 million years ago), period and genus filters, an *only Pterodactylus* button, and search.
- Nearest fossil to you, computed in the browser. Your location is never sent anywhere.
- Latest pterosaur science news. Satire, viral-video and "living pterosaur" sighting stories are filtered out.

`build.py` (standard-library Python) runs daily via GitHub Actions and deploys to Pages.
